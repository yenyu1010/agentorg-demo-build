# Audience Profiles

## executive（管理層）
- **受眾**：完全不懂軟體的主管、決策者
- **用語策略**：零技術術語。agent = 虛擬助理、workflow = 自動化流程、dispatch = 分派工作
- **內容深度**：只講效益和成果，不提實作細節
- **範例風格**：商業案例 — 「節省 X 小時」、「減少 Y% 錯誤」
- **簡報長度**：PPT 10-15 頁、Word 3-5 頁

## developer（開發者）
- **受眾**：會寫程式的工程師
- **用語策略**：直接用技術術語。YAML、JSON、Claude API、soul.md
- **內容深度**：完整架構圖、檔案結構、workflow 流程、程式碼範例
- **範例風格**：實際 agent 呼叫範例、workflow.yaml 片段、dispatch prompt 範例
- **簡報長度**：PPT 20-30 頁、Word 10-20 頁

## power-user（進階使用者）
- **受眾**：非工程師但會操作 CLI 的人（PM、QA）
- **用語策略**：解釋技術術語但不避開它們
- **內容深度**：教操作步驟、常見指令、錯誤處理
- **範例風格**：Step-by-step 教學、常見問題 FAQ
- **簡報長度**：PPT 15-20 頁、Word 5-10 頁
