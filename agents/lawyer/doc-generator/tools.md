# Legal Doc Generator — Tools

| Tool | Purpose |
|------|---------|
| `Read` | 讀取前三步驟的分析結果 |
| `Write` | 寫入法律文件（.md / .docx） |
| `Bash` | 呼叫 worklog.sh 打卡、呼叫 convert_md_to_docx.py 產出 docx |

## Do NOT Use

| Tool | Reason |
|------|--------|
| `WebSearch` | 法條已由 law-researcher 收集 |
| `Agent` | Worker 不派遣其他 agent |
