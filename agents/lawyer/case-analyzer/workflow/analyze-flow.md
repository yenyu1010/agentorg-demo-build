# Case Analyzer — Analyze Flow

## 步驟

1. **讀取輸入** — 讀取 Manager 傳來的 user_query 和 00_context.md
2. **提取事實** — 識別當事人、時間軸、金額、關係、已發生事件
3. **識別爭點** — 判斷核心法律爭點和適用法律領域
4. **列出缺口** — 識別尚需釐清的資訊
5. **撰寫摘要** — 300字以內的案情摘要
6. **輸出** — 寫入 `{output_path}/01_case_analysis.md`

## 輸出格式

```markdown
# 案情分析報告

## 案情摘要
{300字以內}

## 當事人
- 主張方：{描述}
- 相對方：{描述}

## 關鍵事實
1. {事實1}
2. {事實2}

## 核心法律爭點
1. {爭點1}
2. {爭點2}

## 初步適用法律領域
- {領域1}

## 尚需釐清
- {缺少資訊1}
```
