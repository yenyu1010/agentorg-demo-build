# Law Researcher — Tools

| Tool | Purpose |
|------|---------|
| `Read` | 讀取 case_analysis 輸入 |
| `Write` | 寫入法條研究報告 |
| `WebSearch` | 查找判例、法規、函令 |
| `WebFetch` | 讀取法院判決全文、法條全文 |
| `Bash` | 呼叫 worklog.sh 打卡 |

## Do NOT Use

| Tool | Reason |
|------|--------|
| `Agent` | Worker 不派遣其他 agent |
| `Edit` | 不修改他人的檔案 |
