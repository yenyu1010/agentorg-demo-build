# Value Betting Modeler — Skills

## 1. 勝率估計（雙法並用）

### 方法 A：加權評分法
1. 讀取 form-analyst 的狀態評分（近期勝率、主客場差異、H2H、傷停動機）
2. 計算狀態分差 Δ = home_score − away_score
3. 套用主場優勢修正（預設 +0.05 p_home；若中立場地則 0）
4. 套用 H2H 修正（近 5 場主方勝出比例偏離 0.5 超過 0.15 → ±0.03）
5. 套用傷停動機修正（核心球員缺陣 ≥ 2 → −0.04；關鍵晉級場次 → +0.03）
6. 以 logistic 函數映射為 p(主勝)、p(和)、p(客勝)，三者加總必等於 1.00

### 方法 B：簡化 Poisson
1. 讀取 form-analyst 提供的 λ_home（主隊場均進球）、λ_away（客隊場均進球）
2. 建立比分機率矩陣（主隊 0–6 球 × 客隊 0–6 球，共 49 格）
3. 每格機率 = Poisson(λ_home, i) × Poisson(λ_away, j)
4. 加總得：p(主勝)、p(和)、p(客勝)；延伸計算大球 / 小球覆蓋機率（2.5 球門檻）；亞盤覆蓋機率（依盤口調整）
5. 所有 Poisson 計算必須以 Python 腳本執行，不可心算

### 雙法整合
- **最終 p_model** = (方法 A + 方法 B) 的平均值
- 若兩法對同一市場的機率差異 > 10 個百分點 → 於報告標註「模型分歧，信心降級」

## 1c. 滾球剩餘進球估計（In-Play Remaining-Goals via Half-Split λ）

當 manager 提供「當前比分 + 比賽時間」時，啟用此流程取代整場平均外推。

### 核心原則
**嚴禁**使用整場平均 λ 平均外推剩餘進球期望。滾球狀態下的進球率不均勻，必須使用 form-analyst 的分半 λ 來估計剩餘期望。

### 分半 λ 縮放計算
1. 判斷當前處於上半場（≤ 45'）或下半場（46'–90'）
2. 取對應分半 λ：
   - 上半場剩餘 → 使用 λ_1H_for / λ_1H_against
   - 下半場剩餘 → 使用 λ_2H_for / λ_2H_against
3. 按剩餘時間比例縮放：
   - `λ_remaining = λ_half × (剩餘分鐘 / 45)`
   - 例：60 分鐘（下半場已進行 15 分鐘，剩 30 分鐘） → `λ_remaining = λ_2H × (30/45)`
4. 以縮放後的 λ 建立剩餘比分機率矩陣（最高附加 5 球範圍即可）

### 球隊類型修正（疊加）
依 form-analyst 回傳的球隊類型標籤調整剩餘 λ：
- **領先方為關門型** → 下調其 λ_remaining × 0.80（防守收緊，進球驟降）
- **落後方 + 對手為尾盤崩盤型** → 上調落後方 λ_remaining × 1.20（追分壓力 + 對手防線崩潰風險）
- 無類型標籤 → 不調整，使用原始縮放值

### 比賽狀態（Game-State）修正（疊加）
- 一方大幅領先（≥ 2 球差）且剩餘時間 ≤ 15 分鐘 → 全場 λ_remaining 均下調 × 0.85（整體降速）
- 落後方需追分且剩餘 ≥ 15 分鐘 → 落後方進攻 λ 上調 × 1.15，但同時其防守 λ 上調 × 1.20（反擊失球風險）

### 輸出
- 滾球大球 / 小球各線的剩餘期望進球 + P（覆蓋機率） + EV
- push / 四分之一盤退款處理照 5b 節規則辦理
- 輸出標注「基於分半 λ 估計，時間截點：[比賽時間]'，比分：[比分]」

## 1d. 水位隱含機率對照（Market-Implied vs Model）

滾球估計**必須雙軌並陳**：(a) 自己的分半 λ Poisson 機率，(b) odds-analyst 提供的即時水位去水隱含機率。

### 使用前提：先去水
- **嚴禁**以原始賠率（含抽水）直接當機率使用
- 必須要求 odds-analyst 提供「去水後隱含機率」（water-removed implied probability）
- 換算公式：`p_i = (1/odds_i) / Σ(1/odds_j)`

### 雙軌對照規則
<!-- governance-fix 2026-06-13 -->
| 情況 | 處理方式 |
|------|---------|
| 兩者差異 ≤ 5% | 取加權平均（市場 60% + Poisson 40%）|
| 兩者差異 5%–15% | 市場主導，**但 Poisson 保留最低 25% 權重（不得歸零）**；輸出標注「⚠ 分歧 X%，市場主導 / Poisson ≥25%」|
| 兩者差異 > 15% | **不採市場為唯一依據**；改為「降級為觀望或降信心 1–2 級」並標注「⚠⚠ 大幅分歧 X%，雙方必有一方估錯，建議獨立判斷，不盲從市場」|

> **F-1 說明**：高分歧時 Poisson 權重歸零等同純抄盤，失去模型存在的意義。分歧 >15% 代表市場與模型至少一方嚴重錯誤，此時最保守的正確做法是降低信心、觀望，而非單向押注市場必對。

**市場優先原則（滾球核心邏輯）**：即時盤包含場上即時資訊（比賽節奏、傷停、輪換、大額資金），Poisson λ 是賽前估計，滾球狀態下已部分過時。市場水位的即時性通常優於事前模型，分歧時以市場為主——但**採市場主導時仍須保留「此移動可能為莊家陷阱盤／誘盤」的可能性**（參見 §3 反向訊號邏輯），不得單向假設市場一定正確。
<!-- /governance-fix -->

### EV 計算仍用實際賠率
- 此對照**僅用於修正 p_model 勝率估計（水位水準 level）**，不改變 EV 計算所使用的實際賠率
- EV 計算公式不變：`EV = p_model_adjusted × odds − 1`

<!-- governance-fix 2026-06-13 -->
### 水位訊號使用分工（避免 double-counting）

水位數據**只能在下列兩個用途中各用一次，嚴禁同一訊號重複使用**：

| 用途 | 使用維度 | 對應節點 | 作用 |
|------|---------|---------|------|
| **修正 p_model** | 水位**水準（level）**——去水後隱含機率數值 | 本節（1d） | 調整勝率估計 p_model_adjusted |
| **調整信心係數** | 水位**移動（movement）**——異常變化方向與幅度 | §3 賠率訊號融合 | 加減信心 ±1 |

- 1d 的「雙軌對照」**只看水準值**（去水隱含機率 vs Poisson 機率），更新 p_model。
- §3 的訊號融合**只看移動方向**（盤口縮水、資金異動方向），調整信心係數。
- **嚴禁**：以水位移動方向既修正 p_model（1d），又在 §3 再次以同一移動調整信心；或以水位水準既調了信心，又在 §3 重複計入。
<!-- /governance-fix -->

### 誠實規則
- **低流動性聯賽**（非五大聯賽、非亞冠/歐冠）：水位噪音大，標注「市場訊號信心降級，雙軌對照參考價值有限」
- odds-analyst 未提供即時水位時：回退為純 Poisson 估計，並標注「[⚠ 市場水位缺失，僅用 Poisson 單軌]」
- **不得自行臆測水位方向**——水位數據必須來自 odds-analyst，模型不可虛構

### 輸出格式（嵌入 1c 輸出後）
```
市場：大球 2.5
  Poisson 機率：48.3%（分半 λ 估計）
  市場水位隱含機率：53.2%（odds-analyst 去水後）
  分歧：+4.9% ← 市場略高於模型
  採用 p_model_adjusted：51.4%（加權平均）
  移動方向：↑收縮，進球臨近訊號：⚡
```

## 1e. 即場進球機率公式（Goal-from-Line：市場線基準；水位移動僅供參考）

### 核心紀律（來自愛沙甲 MISS）

**即場判「上半／後續有沒有球」必須以市場即時大小線為 baseline，禁止用射正／控球等眼球觀察單向覆蓋市場線。**

- 反例（愛沙甲 32'）：我用 0 射正覆蓋 2.5 線，喊無球 72% → 看錯。
- 若以本公式計算，同情境約給出 40% 進球 / 60% 無球——較 humble，會阻止過度自信的單向判斷。

> ⚠️ **禁止把分鐘級大球水收/放當進球訊號——實測證明進球常在大球水最冷時發生。**
>
> 用戶 2026-06-14 實測數據（競技會MG vs 戈亞斯、卡拉雷聯 vs 智利大學多場上半進球前時間序列）：
> 進球前大球水「多在變冷（升水）」而非收緊——時間衰減主導水位，不是進球預測。
> 例：競技會MG 0-0 期間，大球水 03:38（0.85）→ 03:47（1.14）持續升冷 → 03:48 進球。
> 卡拉雷聯三個上半進球前表現相同。
> **結論：分鐘級水位移動讀不出進球；能預測的是「線的水準（L）」，不是水位熱度。**

---

### 公式定義

**符號**

| 符號 | 意義 |
|------|------|
| L | 即時大小球盤口線（即時市場大小線，由 odds-analyst 提供） |
| G | 現比分總球數 |
| m | 當前比賽分鐘（滾球時刻） |
| T_end | 目標時段結束時間（上半 = 45；全場後續 = 90） |

**步驟一：剩餘期望進球**
```
剩餘期望進球 = L − G
```

**步驟二：目標時段剩餘強度 λ**
```
λ = (L − G) × (T_end − m) / (90 − m) × K

  其中：
  K = 0.9（目標時段為上半場，強度略低係數）
  K = 1.0（目標時段為全場後續）

  時間衰減因子 (T_end − m) / (90 − m)：
  - m 越接近 T_end → 衰減因子 → 0 → λ → 0
  - 自然內建「越近時段結束越不看好進球」邏輯
```

> ⚠️ 係數 K=0.9 與時間衰減分母為啟發式假設，需累積樣本校準（n≥15 後回填 track-record）。

**步驟三：進球機率**
```
P(該時段再進球) = 1 − exp(−λ)
```

所有計算必須以 Python 腳本執行（Poisson 計算紀律，見 §7）。

### 15'/30' 檢查點操作法（即場上半進球判斷）

<!-- refined 2026-06-14 user-data -->

**核心原則：檢查的是「線的水準（L）」，不是水位熱度。**

即場判斷上半是否有球，在以下兩個標準時點讀線算 P：

| 檢查點 | 操作 |
|--------|------|
| **15'** | 取當下 L（上半大小線），套公式：λ = (L − G) × (45 − 15) / (90 − 15) × 0.9，算 P |
| **30'** | 取當下 L（上半大小線），套公式：λ = (L − G) × (45 − 30) / (90 − 30) × 0.9，算 P |

**操作說明**：
1. 讀取當時 odds-analyst 提供的即時大小線 L（不是開賽線，是即時盤）
2. 套公式計算 λ 與 P（必須用 Python 腳本）
3. 對照盤口賠率算 EV，仍套用 EV ≥ 3% 且信心 ≥ 3 門檻
4. **判斷依據是 L 的水準本身**（線高 = 市場認為進球機率高）；**不看水位是否「熱」**

**反例（用戶實測，2026-06-14）**：
> 戈亞斯 30' 時大小線 L = 1（極低），套公式：λ = (1 − 0) × 15/60 × 0.9 ≈ 0.225，
> P ≈ 20%（低）→ 建議觀望。**實際上半僅 1 球** ✓。
> 關鍵：不是因為水位冷熱，是因為線本身低（L=1）告訴你市場不預期多球。

---

### 與 EV 結合

1. 以調整後 λ 算出 P(進球)
2. 對照盤口實際賠率計算 EV：`EV = P × odds − 1`
3. 仍套用硬性門檻：EV ≥ 3% **且** 信心 ≥ 3，方可建議投注（同 §4 規則）

---

### 誠實標註與校準掛鉤

> 本公式為**啟發式估算**，非統計驗證公式。
> 回測案例（n 極小）：
> - 愛沙甲（公式給 40% 進球）→ 實際有球 ✓ humble 阻止了錯誤
> - 西澳（公式給 ~1% 進球）→ 實際無球 ✓
> - 科威特（公式給 ~26% 進球）→ 待後續驗證
> - 戈亞斯 30'（公式給 ~20% 進球，L=1 線低）→ 上半 1 球 ✓（2026-06-14 用戶實測）
>
> **主要作用**：防過度自信，非神準預測工具。
> K=0.9 係數與時間衰減分母（90−m）均標記為「需累積樣本校準」。
>
> **2026-06-14 更新說明**：依用戶實測數據降級水位移動疊加，移除「大球水放鬆 → 降 λ」規則，
> 新增 15'/30' 檢查點操作法與「進球前大球水常為升冷」警語。

## 1e-操作規則（Operation Rules — 驗證經驗固化）

> 本節為「已有實測支持的操作教訓」提升為明文規則。純新增，不刪改公式本體。

### 規則 OR-1：優先使用上半場大小線（不得用全場線推）

**何時適用**：在 15'/30' 檢查點判斷「上半是否有球」時。

**規則**：
1. 若 odds-analyst 提供「上半場大小線」直接數字 → **必須直接使用該數字作為 L**，套入公式計算。
2. 若**僅有全場線、無上半線** → 才允許退回以「全場線 × 時間衰減」推估，但**必須在輸出標注「[⚠ 無上半線，全場線外推，精度降低]」**。

**反例（荷日，2026-06-14 實測）**：全場線 2.4 推出 56% 偏高；直接看上半線 1.5 則更貼近實際無球環境。
**教訓**：上半線比全場線更能直接反映市場對上半進球的預期，勿捨近求遠。

---

### 規則 OR-2：保守看待上半進球概率（實證校準，正式生效）

**背景**：即時實測樣本（非回測）顯示，§1e 公式系統性高估上半進球概率：
- 荷日（WC）@17'，P=56% → 實際 HT 0-0 無球
- 亞歷山大紅人（美國超）@27'，P=51% → 實際上半無球
- 華利祖（秘魯聯盃）@28'，P=39% → 實際上半無球
- 累計 3/3 即時樣本偏向「公式給有球機率、實際無球」

**可能原因**：
- 上半進球 back-loaded（第一球常在 25–40' 後段，15'/30' 檢查點時「還早」）
- 線性時間分配 `(T_end − m) / (90 − m)` 高估早段進球密度
- 低分環境（世界盃、盃賽、小聯賽）先驗進球率本就低，而線性公式未做環境修正

**操作規則**（在 K 正式校準前，即 n < 10 的過渡期）：
1. **低分環境先驗修正**：當場次屬於世界盃、盃賽性質賽事、或小聯賽（非五大聯賽、非亞歐冠）時，公式輸出的上半進球 P 需**主觀降一格**看待（例如：公式給 50% → 視為 ≤45%；公式給 39% → 視為 ≤35%）。
2. **出手門檻提高**：判斷「有球」方向投注時，在低分環境下要求更高的 EV 邊際（≥5%，而非標準的 ≥3%），反映公式高估的系統性風險。
3. **非對稱原則**：「寧可低估（錯過）不高估（誤投）」。偏樂觀的公式輸出，應以偏保守的出手決策補償。
4. 此規則持續有效，直至 n≥10 即時樣本後正式評估 K 是否下修（0.9 → 0.75 或改用非線性分配）。

引用依據：calibration-notes.md §「校準訊號:公式可能高估上半進球（2026-06-15）」

### 規則 OR-3：線級為核心、水位移動降級（對照組驗證確認）

**結論（2026-06-14 用戶無球對照組驗證）**：
- **線級（L 的水準值）**：能有效 discriminate 進球環境。高線（L ≥ 2）→ 有球場；低線（L ≤ 1.5）→ 無球場。公式核心邏輯驗證通過。
- **水位移動（分鐘級升降）**：有球場與無球場的水位移動模式**完全相同**（皆為時間衰減主導的升冷），無 discrimination 力。

**操作規則**：
1. 即場進球判斷以**線級 L 的數值**為主要輸入，這是本公式的合法訊號。
2. **水位移動方向**（收緊 / 放鬆 / 升降）不得作為「有球 / 無球」的判斷依據，已明確降級為「不調整 λ（除罕見強訊號例外，見上方表格）」。
3. 若用戶或 manager 提到「大球水在收緊，應該有球」→ 應明確告知：「實測顯示水位移動無 discrimination 力，判斷依據是線級 L，而非水位熱度。」

引用依據：calibration-notes.md §「無球對照組驗證（2026-06-14）」

## 2. 期望值計算（EV Computation）

對所有可投市場（1X2 主勝 / 和局 / 客勝、亞盤主讓 / 亞盤客讓、大球 / 小球）逐一計算：

```
EV = p_model × odds − 1
```

- EV > 0 → 市場報酬率高於公平賠率，存在 value
- EV ≤ 0 → 無 value，直接標記 pass
- 所有計算在 Python 腳本執行，輸出包含各市場 EV% 排序表

---

## 3. 賠率訊號融合（Odds Signal Integration）

1. 讀取 odds-analyst 提供的異常訊號（資金方向、盤口移動、水位變化）
2. 依下列規則調整信心係數（1–5 分，基準為 3）：
   - 機構資金方向與 p_model 同向 → 信心 +1
   - 機構資金方向與 p_model 反向 → 信心 −1，並附注「市場可能知道你不知道的事」
   - 水位異常升高（去水量 > 15%）→ 信心 −1
   - 賠率穩定無異動 → 信心維持不變
3. 信心係數影響最終建議：信心 ≤ 2 → 強制 pass，不論 EV 多高

---

## 4. 注碼建議（Fractional Kelly）

```
f* = (p × b − q) / b
    其中：b = odds − 1，q = 1 − p_model
實際注碼 = 0.25 × f*（採四分之一 Kelly 降低波動）
```

**硬性上限與 pass 條件**：
- 單場注碼上限：bankroll 的 2%
- EV < 3% → 強制 pass（即使有 value 也嫌太薄）
- 信心 ≤ 2 → 強制 pass
- f* < 0（EV 本就為負）→ 強制 pass
- pass 也是建議，不是失敗

所有 Kelly 計算必須以 Python 腳本執行，結果附於報告。

---

## 5. 最優投報率排序（Top Picks Ranking）

1. 計算每個市場的綜合得分 = EV% × 信心係數
2. 降序排列，輸出 Top 3 picks（或全部通過門檻的市場）
3. 若**所有**市場均 pass → 明確輸出「本輪無建議投注」（誠實性核心，嚴禁強行給出推薦）

**輸出格式**：

| 場次 | 市場 | 方向 | 賠率 | p_model | 隱含p | EV% | 0.25Kelly注碼% | 信心(1-5) |
|------|------|------|------|---------|-------|-----|---------------|-----------|

## 5b. 勝率分層輸出（Win-Probability Tier）

每次全市場掃描後，除 EV 推薦表外，**必須**輸出第二張表「高勝率參考榜」。

### 篩選條件
列出所有 p_model（含退款處理後的有效勝率）**≥ 55%** 的受讓（亞盤）、大小球、獨贏（1X2）市場，按勝率降序排列。

### 退款處理（整數盤 / 四分之一盤）
- 整數盤（如 0 球）：push 退款需折算有效勝率：`p_eff = p_win + p_push × 0`（退款不計為勝），退款率 = p_push
- 四分之一盤（如 -0.25 / +0.25）：半贏半退 → `p_eff = p_win + 0.5 × p_push`；半輸半退 → `p_eff = p_win`；退款率 = p_push
- 所有折算必須以 Python 腳本計算，並於報告列出退款率欄位

### 輸出表格欄位

| 市場 | 方向 | 賠率 | 勝率% | 退款率% | EV% | 長期每注期望 |
|------|------|------|-------|---------|-----|------------|

> 「長期每注期望」= EV% 換算為每投 1 單位的期望盈虧（EV% × 1 = 期望值，保留兩位小數）

### 分層標示
- **★推薦**：EV ≥ +3%（與 EV 軸結果一致）
- **◐可考慮**：−3% < EV < +3%（接近公平價，購買的是低波動而非正期望）
- **✗不建議**：EV ≤ −3%（長期支付溢價，純粹買高命中率）

### 誠實標籤（天條）
榜首必附以下說明，**不得省略、不得改寫**：

> 勝率高≠會賺：EV 為負的高勝率單長期必虧（贏的次數多但單注賺得少、輸一次賠得多）。此榜供「低波動偏好」自行斟酌，模型的正式推薦仍以 EV 軸為準。

### 若無市場達 55% 門檻
輸出「本輪無高勝率市場（所有市場 p_model < 55%）」，不強行填表。
