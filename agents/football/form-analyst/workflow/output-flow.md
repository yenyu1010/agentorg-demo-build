# Form Analyst — Output Flow

## 目標

將 analyze-flow 的六維分析結果組裝為標準對照表格式，寫入 output_path 供 value-modeler 消費。

---

## 輸出格式

```markdown
# 球隊狀態分析報告

**賽事**：{home_team} vs {away_team}
**比賽日期**：{match_date}
**分析時間**：{ISO8601_timestamp}
**資料來源**：{titan007 / WebSearch / 混合（詳見底部來源清單）}

---

## 一、綜合對照表

| 指標 | {主隊} | {客隊} |
|------|--------|--------|
| 近 6 場戰績（W/D/L） | {W-D-L} | {W-D-L} |
| 加權狀態分（0-10） | {score} | {score} |
| 主/客場戰績（近 5 場） | 主場 {W-D-L} | 客場 {W-D-L} |
| 主/客場場均進球 | {avg} 球 | {avg} 球 |
| 主/客場場均失球 | {avg} 球 | {avg} 球 |
| 關鍵傷停（高影響） | {player/none} | {player/none} |
| 陣容穩定性 | {穩定/輕微/重大衝擊} | {穩定/輕微/重大衝擊} |
| 動機評級 | {高/中/低} | {高/中/低} |
| 聯賽積分位置 | 第 {N} 位（{pts}分） | 第 {N} 位（{pts}分） |

---

## 二、H2H 摘要

- 近 {N} 次交手：{主隊} {W}勝 {D}平 {L}負
- 相同場地配置（{主隊}主場）：近 {M} 次，{主隊} {W2}勝 {D2}平 {L2}負
- 剋星關係：{描述，如「{主隊}近 5 次交手 3 連勝」或「無明顯優劣」}
- 最近交手：{date}，比分 {score}

---

## 三、Poisson 攻防參數（供 value-modeler 使用）

| 參數 | 數值 | 樣本來源 |
|------|------|---------|

| λ_home_defense（主隊主場失球率） | {value} | 近 {N} 場主場 |
| λ_away_attack（客隊客場進球率） | {value} | 近 {N} 場客場 |
| λ_away_defense（客隊客場失球率） | {value} | 近 {N} 場客場 |

{若樣本不足，在此標注：「⚠️ {主/客}隊主客場樣本量不足（N={n}），λ 值建議謹慎使用」}

---

**{主隊}**：
{2-4 句：陣容健康度、動機背景、近期趨勢的文字描述}

**{客隊}**：
{2-4 句：同上}

**整體形勢觀察**：
{1-2 句：雙方相對動機差異、H2H 心理因素、值得注意的背景資訊}

## 六、資料來源清單

| 資料類型 | 來源 | URL / 搜尋關鍵字 | 抓取時間 |
|---------|------|----------------|---------|
| {主隊}近期戰績 | titan007 | {url} | {timestamp} |

```

---

## 寫入步驟

1. 確認 output_path 目錄存在（若不存在，回報 manager）
2. 使用 `Write` 工具將報告寫入：
   ```
   {output_path}/02_form_analysis.md
   ```
3. 確認寫入成功（檢查無報錯）
4. 若 titan007 本次有新的可用 URL pattern，更新 `memory/titan007-data-map.md`

## 不得寫入的內容

- 任何賠率數字或盤口分析（屬 odds-analyst 領域）
- EV 計算、Kelly 注碼建議（屬 value-modeler 領域）
- 最終勝平負預測（需 manager 整合三方報告後輸出）
