# Form Analyst — Analyze Flow

## 目標

對 fetch-form-flow 輸出的原始資料進行結構化分析，產出六大維度的評估結果。

---

## 步驟

### 1. 近期戰績加權評分

使用近 6 場比賽（若不足 6 場，以實際場次計算並標注樣本量）：

```
預設權重序列（最近場→最遠場）：[3, 2.5, 2, 1.5, 1, 1]
得分規則：W=3 / D=1 / L=0

加權原始分 = Σ(result_score × weight)
最高可能分 = Σ(3 × weight) = 3 × (3+2.5+2+1.5+1+1) = 33
加權狀態分（0-10）= (加權原始分 / 最高可能分) × 10  [保留一位小數]
```

**注意**：若需精確計算，委派 shared/calculator，不可心算。

對主、客隊各執行一次，輸出：
- 近 N 場戰績明細表（對手、比分、W/D/L、場地）
- 加權狀態分（0-10，含計算說明）

### 2. 主客場拆分分析

從 raw_data 中篩選：
- 主隊：僅取主場比賽（home_matches），計算主場加權狀態分
- 客隊：僅取客場比賽（away_matches），計算客場加權狀態分

各取近 5 場主/客場記錄，輸出對照表。

### 3. H2H 對賽往績歸納

分析步驟：
1. 統計近 5-10 次 H2H 總體勝負（主隊視角：W/D/L）
2. 篩選「相同主客場配置」（主隊在主場）的歷史場次
3. 識別模式：連勝/連負序列（≥3 場相同結果視為剋星關係）
4. 最近一次交手距今天數（新鮮度評估）

輸出：
- H2H 統計表（近 N 場）
- 相同場地配置下的歷史（若有）
- 剋星關係描述（質化，明確說明依據場次）

### 4. 陣容與傷停評估

對每位傷/停球員評估影響等級：

```
高影響：主力首發（門將、核心前鋒/中場）且無直接替補方案
中影響：輪換球員或有備選方案的主力
低影響：板凳球員或非關鍵位置
```

多線作戰風險：若隊伍本週有杯賽（歐冠/國內杯），評估輪換可能性。

輸出：
- 傷停名單表（球員、狀態、影響等級、消息來源、消息日期）
- 陣容穩定性總評（穩定/輕微衝擊/重大衝擊）

### 5. 動機與形勢評級

```
積分位置評估：
  - 距聯賽冠軍/第4（歐冠位）/保級線的分差
  - 是否已提前確定名次（低動機警示）

動機評級標準：
  高：必勝場（保級生死戰、爭冠決戰、同城德比、盃賽決賽）
  中：有意義但非迫切（歐戰資格爭奪、正常主場積分需求）
  低：無欲行情（已確定降級/奪冠、杯賽已出局、賽季末）
```

輸出：兩隊動機評級（高/中/低）+ 理由（1-2 句）

### 6. Poisson 攻防參數萃取

計算以下四個 λ 候選值（均基於主客場場次，非總戰績）：

```
λ_home_attack  = 主隊主場場均進球（近 N 場主場）
λ_home_defense = 主隊主場場均失球（近 N 場主場）
λ_away_attack  = 客隊客場場均進球（近 N 場客場）
λ_away_defense = 客隊客場場均失球（近 N 場客場）
```

格式範例：「λ_home_attack = 1.75（近 8 場主場，樣本量 N=8）」
若主客場場次不足 4 場，標注「樣本量不足，建議謹慎使用」。
