# Odds Analyst — Analyze Movement Flow

## 目的

對抓取到的原始賠率數據進行三層分析（隱含機率 → 變化追蹤 → 異常訊號），並格式化輸出完整的結構化賠率報告。

## 分析流程

### 層次一：去水隱含機率計算

對每家公司的即時盤（或初盤，若即時盤不可用）計算去水隱含機率：

```
overround = (1/odds_1) + (1/odds_X) + (1/odds_2)
p_1 = (1/odds_1) / overround
p_X = (1/odds_X) / overround
p_2 = (1/odds_2) / overround
抽水率 = overround - 1（以百分比表示）
```

> ⚠️ 複雜計算（多公司平均、加權等）委派 shared/calculator，不得心算。

### 層次二：賠率變化追蹤

對每家公司計算初盤 → 即時盤變化：

```
變化幅度 = 即時盤賠率 - 初盤賠率
變化方向：正值 = 賠率拉升（該選項被壓低預期）/ 負值 = 賠率壓低（資金湧入）
```

識別：
- **主流共識**：≥ 80% 公司同方向變化 → 標注「市場共識」
- **個別背離**：某公司變動方向與主流相反 → 標注「背離訊號」（重點關注）

### 層次三：亞盤訊號解讀

| 變化類型 | 解讀 |
|---------|------|
| 盤口升（如 半球 → 半一） | 上盤（主隊）被看好，資金流向主隊 |
| 盤口降（如 半一 → 半球） | 下盤（客隊）被看好，資金流向客隊 |
| 上盤水位 < 1.85 | 大量資金湧入上盤，盤口可能繼續升 |
| 下盤水位 < 1.85 | 大量資金湧入下盤，盤口可能繼續降 |
| 大小球盤口升 | 市場預期進球數增加 |

### 層次四：異常訊號偵測

逐一檢查以下異常模式，每個命中訊號按格式輸出：

| 訊號類型 | 判定條件 | 強度基準 |
|---------|---------|---------|
| 強隊賠率不降反升 | 排名較高一方賠率升幅 > 0.10 | 幅度 0.1-0.2 → 3；> 0.3 → 5 |
| 開盤即深盤 | 初盤亞盤盤口 ≥ 1.5 球 | 1.5 球 → 3；≥ 2 球 → 5 |
| 臨場急變 | 賽前 2 小時內賠率變動 > 0.15 | 幅度 0.15-0.25 → 3；> 0.35 → 5 |
| 主流公司集體縮水 | ≥ 70% 公司同時降低最高限注 | 出現即為 4 |
| 歐賠亞盤背離 | 歐賠看好主隊但亞盤資金流向客隊 | 背離明顯 → 4 |

- 所有數字必須來自 `RAW_EUROPE_ODDS` 或 `RAW_ASIA_ODDS`，禁止填入估算值
