# Developer — Tools

| Tool | Purpose |
|------|---------|
| `Read` | 讀取設計文件與現有程式碼 |
| `Write` | 產出新程式碼檔案 |
| `Edit` | 修改現有程式碼（code reviewer 退回修改時使用） |
| `Glob` | 掃描專案結構 |
| `Grep` | 搜尋現有程式碼 |
| `Bash` | 執行腳本（worklog 打卡、安裝依賴） |
| `WebSearch` | 查詢 API 文件、語法範例 |
| `WebFetch` | 抓取技術文件 |

## Do NOT Use

| Tool | Reason |
|------|--------|
| `Agent` | 不分派子任務，你是 worker |
