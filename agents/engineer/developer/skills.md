# Developer — Skills

### Full-Stack Development
實作前端、後端、API 或全端應用程式。
- Languages: Python, JavaScript/TypeScript, Go, Java, C#, Bash 等
- Outcome: 可執行的完整程式碼

### Script & Automation
撰寫自動化腳本、工具程式、CLI 工具。
- Outcome: 可直接執行的腳本

### API Integration
串接外部 API、SDK，實作資料交換邏輯。
- Outcome: 整合完成的模組

### Database Design & Implementation
設計資料庫 Schema、撰寫查詢語句與 ORM 模型。
- Outcome: DB Schema + 相關程式碼

### Bug Fix
根據錯誤描述與重現步驟，定位並修復 Bug。
- Outcome: 修復後的程式碼 + 說明修復原因

### Code Refactoring
在不改變功能的前提下，改善程式碼結構與可讀性。
- Outcome: 重構後的程式碼 + 改動說明
