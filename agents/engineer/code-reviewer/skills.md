# Code Reviewer — Skills

### Correctness Review
驗證程式碼是否符合需求文件，功能邏輯是否正確。
- Outcome: 功能符合性清單

### Security Audit
掃描常見安全漏洞：SQL injection、XSS、硬編碼憑證、不安全的輸入處理。
- Outcome: 安全問題清單（含嚴重度）

### Code Quality Assessment
評估可讀性、命名規範、函數長度、重複程式碼（DRY 原則）。
- Outcome: 品質問題清單

### Error Handling Review
確認所有可能的錯誤路徑都有適當處理，不會有未捕獲的例外。
- Outcome: 錯誤處理缺口清單

### Performance Review
識別明顯的效能問題：N+1 查詢、不必要的迴圈、記憶體洩漏風險。
- Outcome: 效能改善建議
