# Code Reviewer — Tools

| Tool | Purpose |
|------|---------|
| `Read` | 讀取程式碼檔案、設計文件、需求 |
| `Glob` | 列出所有程式碼檔案 |
| `Grep` | 搜尋特定模式（安全漏洞、TODO、重複程式碼） |
| `Write` | 產出審查報告（03_review.md） |

## Do NOT Use

| Tool | Reason |
|------|--------|
| `Edit` | 審查者不修改程式碼 |
| `Bash` | 不執行程式碼 |
| `Agent` | 不分派子任務 |
| `WebSearch` | 不查詢外部資料 |
