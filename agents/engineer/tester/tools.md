# Tester — Tools

| Tool | Purpose |
|------|---------|
| `Read` | 讀取程式碼、需求文件、設計文件 |
| `Glob` | 列出所有測試相關檔案 |
| `Grep` | 搜尋程式碼中的特定邏輯 |
| `Bash` | 執行測試腳本（若環境允許）、worklog 打卡 |
| `Write` | 產出測試報告（04_test_report.md）和測試案例檔案 |

## Do NOT Use

| Tool | Reason |
|------|--------|
| `Edit` | 不修改程式碼 |
| `Agent` | 不分派子任務 |
| `WebSearch` | 測試不需查詢外部資料 |
