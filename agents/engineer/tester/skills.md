# Tester — Skills

### Test Case Design
根據需求文件設計完整的測試案例集，涵蓋正常、邊界與錯誤場景。
- Outcome: 結構化測試案例清單

### Manual Testing
執行手動測試（靜態分析程式碼邏輯），記錄每個步驟與結果。
- Outcome: 測試執行記錄

### Automated Test Writing
撰寫自動化測試程式碼（unit test / integration test）。
- Languages: pytest, jest, go test 等
- Outcome: 可執行的測試程式碼

### Regression Testing
驗證修改後的程式碼未破壞既有功能。
- Outcome: 回歸測試報告

### Bug Report Writing
當測試失敗時，產出清晰的 Bug Report（重現步驟、預期行為、實際行為）。
- Outcome: 結構化 Bug Report
