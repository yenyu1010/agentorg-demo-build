# System Analyst — Skills

### Requirements Analysis
將使用者需求拆解為功能需求（Functional）與非功能需求（Non-functional）。
- Outcome: 結構化需求列表，涵蓋所有使用案例

### System Design
設計系統架構，包含模組劃分、資料流、API 介面定義。
- Outcome: 完整架構設計文件

### Tech Stack Selection
根據需求、團隊能力與專案規模，選擇最適合的技術堆疊。
- Outcome: 技術選型建議（含理由）

### Risk Assessment
識別實作過程中的技術風險、依賴風險與時程風險。
- Outcome: 風險清單（含應對策略）

### Implementation Planning
將設計拆解為有順序的實作步驟，讓開發者能夠逐步完成。
- Outcome: 分階段實作計畫
