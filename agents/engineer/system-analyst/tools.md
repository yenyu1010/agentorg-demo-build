# System Analyst — Tools

| Tool | Purpose |
|------|---------|
| `Read` | 讀取現有程式碼、文件，理解現有系統 |
| `Glob` | 掃描專案結構 |
| `Grep` | 搜尋相關程式碼片段 |
| `WebSearch` | 查詢技術文件、最佳實踐 |
| `WebFetch` | 抓取特定技術文件頁面 |
| `Write` | 產出設計文件（01_design.md） |

## Do NOT Use

| Tool | Reason |
|------|--------|
| `Edit` | 不修改程式碼 |
| `Bash` | 不執行腳本 |
| `Agent` | 不分派子任務 |
