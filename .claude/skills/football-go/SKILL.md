## 用途 / Purpose

計算足球走地（in-play）過程中大小球（over/under）水位變化，判斷：
- **(a)** 上半場是否會進球
- **(b)** 後續是否還有進球

透過選場條件過濾 + 走地水位訊號監控，輸出 GO / WAIT / SKIP 綜合訊號。

---

## 術語 (Terminology)

| 術語 | 說明 |
|------|------|
| 水位 | 賠付賠率（odds）。數字越低代表莊家越看好該方向。 |
| 升水 | 賠率數字升高 → 該邊買的人少，莊家鼓勵買入。 |
| 降水 | 賠率數字降低 → 買該方向的人多，莊家降低吸引力。 |
| 降盤 | 總進球線下移（如 2.5 → 2.25 → 2.0），通常隨比賽時間遞減。 |
| 大球 (Over) | 押總進球數超過當前盤口線。 |
| 小球 (Under) | 押總進球數低於當前盤口線。 |
| 讓球盤 (Asian Handicap) | 主隊讓幾球，負值=主讓，正值=客讓。 |
| 破蛋盤 | 比賽仍 0:0 時出現的特殊盤口。 |
| 射正 (SOT) | Shots on Target，累計射門在門框內次數，反映場面壓力。 |

## A. 選場條件 (Pre-match Filter) — 使用者主判斷【PRIMARY】

1. **讓球盤**：主或客讓 0.5 球以上（`|handicap| ≥ 0.5`）
2. **全場大小球**：開賽盤口 ≥ 大 2.5

> 兩條件皆須通過才進入走地監控；任一不通過 → **SKIP 此場**。

---

## B. 走地核心訊號 (In-play Core Signal) — 使用者主判斷【PRIMARY】

- **小球水位上升（小球升水）達 4–5 次** → 強烈進球訊號。
- 解讀：小球持續升水代表市場/莊家不看好「不進球」，即預期會進球。
- 配合「每次降盤前大球水位一直漲、沒有出現降水」→ 判斷上半場有球。

> 實作門檻：升水次數 **≥ 4 次**即觸發強訊號（5 為經驗上緣）；本 skill 的 analyzer 以 ≥4 判定。

## C. 參考規則 (Reference Rules — 補充訊號 SECONDARY)

> **⚠️ 以下為網路參考資料，補充用，非主判斷；皆為機率性、非穩贏。**

- **參考1**：大球水位 0.8 以上，觀察走地盤大小球變化；降盤過程中每次降盤前大球水位一直上漲、沒出現降水，且場上有射正次數 → 判斷上半場有球；等破蛋盤口出來即可入手。

- **參考2（223 / 334 / 757）**：
  - **223**：比賽 20 分鐘前已進 2 球 → 追上半場第 3 球（上半 2.5 大）
  - **334**：比賽 30 分鐘前已進 3 球 → 追上半場第 4 球（上半 3.5 大）
  - **757**：比賽 75 分鐘前已進 6 球 → 追全場第 7 球（全場 6.5 大）
  - 注：前人統計、較高機率，非 100%，需配合其他判斷。

- **參考3（70–80 分變盤法）**：踢到 70 分後，70–80 分間滾球讓球盤變為平半或受平半，且賠率一邊 ≤ 0.6、另一邊 ≥ 1.4 → 80 分後進球機率極大。
  - 限制：(1) 下半場一開場就是平半/受平半 → 不穩；(2) 適用正規聯賽，青年/友誼/小聯賽不一定；(3) 雙方平均射門需 ≥ 8 次；(4) 賠率越懸殊（一邊 ≤ 0.4、另一邊 ≥ 2.0）越穩；(5) 一方持續升水、一方持續降水最穩。

## D. 計算邏輯 (How the Analyzer Computes)

**輸入**：JSON 時間序列盤口快照，含：
- `pre_match`：賽前選場條件（`handicap`、`total_line`、`over_odds_open`）
- `snapshots`：依 minute 升序的走地盤口快照（`minute`、`score`、`line`、`over_odds`、`under_odds`、`sot` 可選）

**輸出報告（繁體中文）**：
1. **選場檢核** — handicap / total_line pass/fail
2. **小球升水次數** — 逐步比對，列出發生時間與幅度
3. **大球降盤前升水檢查** — 每個降盤點前 over_odds 是否持續上漲
4. **降盤序列** — line 變化時間序列
5. **參考規則命中** — 223 / 334 / 757 自動判斷
6. **綜合訊號** — GO_FIRST_HALF / GO_FULL / WAIT / SKIP，附理由
7. **免責聲明**
