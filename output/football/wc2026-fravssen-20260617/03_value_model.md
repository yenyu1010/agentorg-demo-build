## 四、亞盤深度分析

```
Poisson 分布（λh=2.1, λa=0.9）：
  法贏2球以上（全勝） = 40.9%

亞盤 法讓1球（水0.85，即賠率1.85）：
  EV = 0.409×0.85 + 0.240×(0.5×0.85−0.5×1) + 0.350×(−1)
     = 0.3477 + 0.240×(−0.075) + (−0.350)
     = 0.3477 − 0.0180 − 0.350
     = −0.0203  (−2.03%)

亞盤 塞受讓1球（水1.04，即賠率2.04）：
  EV = 0.350×1.04 + 0.240×(−0.5+0.5×1.04) + 0.409×(−1)
     = 0.364 + 0.240×0.02 + (−0.409)
     = 0.364 + 0.005 − 0.409
     = −0.040  (−4.0%)
```
